# 大肥鱼之家 · 小清新建模组件

这 13 个原生 Godot 场景直接用于 `district/whale_home_map.gd`，可以在编辑器中修改网格、部件位置和尺寸。坐标单位为米；原点位于物件底部，圆窗原点位于窗心，屋瓦原点位于瓦片中心。

| 场景 | 结构与地图用途 |
|---|---|
| `porch_arch.tscn` | 有厚度的拱券、门套、柱脚与柱头；前庭入口 |
| `round_window.tscn` | 凹槽窗框、十字窗格、窗台与支托；三层宅邸的 4 扇圆窗，生成器按半径缩放 |
| `curved_roof_tile.tscn` | 浅弧瓦面、底面与搭接高差；鲸尾屋冠 |
| `tree_tall_green.tscn` | 弯曲分叉树干与高冠叶团；庭院外围，3 棵 |
| `tree_low_green.tscn` | 较低、横向展开的树冠；茶点庭院和前庭，3 棵 |
| `tree_sakura.tscn` | 不对称花簇与分叉；东侧花径，4 棵 |
| `garden_bench.tscn` | 倒角木板、扶手、四脚与斜撑；庭院，4 张 |
| `picket_panel.tscn` | 4 m 的尖头栅栏面板、横梁与端柱；生成器按跨度组合并去除重复接头 |
| `garden_pergola.tscn` | 梁柱接头、斜撑、檐底与弧瓦；两座庭院棚 |
| `flower_bed.tscn` | 浅边框、土层、叶片和花簇；侧庭，8 处 |
| `flower_planter.tscn` | 四壁、底板、空心盆沿和下沉泥土；两座庭院棚下 |
| `dock_post.tscn` | 木桩、柱帽、绳圈和系泊横件；中央栈桥，6 根 |
| `whale_rowboat.tscn` | 双层船壳、底板、肋骨、座板支撑、桨叶、桨锁和系泊眼；海面，2 艘 |

`materials/` 保存共享的奶油、薄荷、鼠尾草绿、粉色和木色材质；`shared_palette.tres` 让程序生成的部件与场景实例使用同一组材质。`meshes/` 保存共享的叶团、叶片、尖头木板和屋瓦网格。重复实例会复用资源。

地图在运行时按材质合并静态网格，同时保留家具节点、碰撞和交互。船只各自在本地合批，船体、鲸鱼和系泊眼一起摆动；系泊绳每帧连接固定码头与移动船眼。柜门、鱼群、灯光和花瓣仍由现有控制器管理。

修改组件后，重新进入“大肥鱼之家”即可加载。若扩大物件外形，需同步调整 `whale_home_map.gd` 中对应碰撞与摆放；门廊、楼梯、三层出口和码头应保留完整人物通行空间。门廊柱体碰撞之间的净宽为 2.26 m，装饰沿两侧柱体布置。屋冠的交替薄荷色由地图生成器设定。

需要从程序源重新生成全部场景时，在项目根目录执行：

```powershell
& 'C:\Users\Administrator\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path . --script res://tools/bake_whale_home_models.gd
```

这个命令会覆盖本目录的生成场景和资源。手工编辑场景后，正常运行地图即可，无需重新生成。对应建模源为 `assets/whale_home/pastel_props.gd`；生成脚本会逐个保存并重新加载组件。

本轮关键行为检查 70 项通过、0 失败；原生 Compatibility 显卡运行确认门廊通路和动态系泊连接。静态合批 212 个表面，两艘船共 16 个表面。画面效果由用户在游戏中检查。
