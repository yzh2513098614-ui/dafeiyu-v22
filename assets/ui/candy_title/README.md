# 糖果贴纸标题素材

与 `ui/candy_sticker_start.gd` 配合使用，完整说明见项目根目录 `00_糖果贴纸开始界面_v22.md`。

| 素材 | 用途 | 来源 |
|---|---|---|
| `backdrop.png` | 标题插画与海洋背景；不含烘焙菜单文字 | 用户整屏参考经 ImageGen 局部编辑移除 UI，保留人物并补绘留空区域。 |
| `logo.png` | 独立透明字标；包含贴纸白边、字腔与鲸鱼白肚 | 用户 Logo 参考经 ImageGen 去外部白底，再作零散蓝点清理。 |
| `icons/*.svg` | 9 个独立菜单符号，72 × 72 | `tools/build_candy_title_icons.py` 原生矢量绘制，可直接编辑路径。 |
| `gallery/whale_wave_source.png` | CG 页面挥手立绘 | 复制项目已有同名源图，保持原图字节；不依赖原目录未提交的文件。 |

`manifest.json` 记录实际尺寸、SHA-256、alpha 属性与来源；`design-brief.json` 记录文字、构图区域与贴纸参数。PNG 本身即生成工具的完整原始输出，未用脚本去色、抠白或改变像素。

复现编辑目标：

1. 对整屏参考仅移除 Logo、八个菜单按钮、右上导航、手写短句、代码符号与底部对话框；严格保留少女的脸、服装、位置、画面光色与海洋边缘，并补齐原 UI 后的背景。界面层由程序重新构建。
2. 对 Logo 参考保留 `token / 之国的 / 大肥鱼` 的字形、吉祥物、厚白边、蓝青偏移底片、白色字腔与鲸鱼肚子，仅使外部画布真正透明。
3. 对透明 Logo 清理外轮廓之外的零散蓝青点；保持现有字形、颜色、白边和偏移底片。

这些是复现目标说明，不冒充逐像素提取结果。参考与实机、参考与透明字标的离线比较页位于 `预览/糖果贴纸开始界面_20261012/`。
