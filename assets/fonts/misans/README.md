# MiSans battle UI fonts

Original, unmodified static font files downloaded from Xiaomi on 2026-10-05:

- MiSans-Demibold.ttf: body text and card titles.
- MiSans-Bold.ttf: resource and card cost numbers.

Official font page: https://hyperos.mi.com/font/zh/

Official package: https://hyperos.mi.com/font-download/MiSans.zip

The original font copyright metadata is retained. MiSans-license.pdf contains the official license agreement. MiSans usage attribution is displayed in the game's settings screens. These fonts are bundled with the game and must not be distributed as a separate font product.

The font binaries are not modified. Godot hinting and rasterization options affect rendering only.
