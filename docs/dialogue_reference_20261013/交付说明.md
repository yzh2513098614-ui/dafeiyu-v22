# 立绘清晰化与示例对话排版

本轮接入 `大肥鱼_数值战斗怪物_v22` 的游戏内对话界面。底部通栏藏蓝面板、细金边、白色姓名牌、原创鲸鱼徽章与蝴蝶结、居中角色，参考用户提供的对话截图。背景继续使用实际游戏场景。标题页、世界角色行走、人物详情、暂停界面与战斗系统未纳入本轮。

## 素材

- `assets/dialogue/whale_clean_generated_20261013.png`：内置 image_gen 以用户图 1 编辑生成，1144×1375，PNG RGBA；alpha 范围 0–255。游戏三个表情槽当前共用这张图，不宣称生成了三个不同表情。
- `assets/dialogue/whale_clean_4k_upscaled_20261013.png`：3408×4096，保留 alpha 的 Lanczos 放大交付版。它不是原生 4K 生成，不新增真实细节。原生版本单独保留，游戏使用原生版本。
- `portrait_prompt.md`：中文 4K 提示词、负面约束与实际提交的英文/中文混合提示词。
- `layout_reference.png`：用户图 2，仅供排版参考，不用整张截图冒充游戏 UI。

对话使用 Godot 导入的 Texture2D 资源，替换本模块的 `Image.load_from_file` 路径。其他模块仍存在原有的图片加载警告，本次不宣称整个项目已具备导出条件。

## 验证与回退

`tools/preview_reference_dialogue.gd` 从真实 `district/continuous_world.tscn` 创建世界和对话控制器，静音并隔离存档。覆盖完整句显示、长句换行、回复显示与分支按钮、自动等待回复、回看、关闭恢复 HUD，以及 1448×1086、1920×1080、1000×750 的实际窗口截图。截图位于 `预览/对话示例排版_20261013/`。

Godot 可编辑页面 `ui/design/pages/dialogue.tscn`、`dialogue_choices.tscn`、`dialogue_backlog.tscn` 和对应基线已同步到新布局，避免每帧设计覆盖将界面改回旧排版。

最终启用真实设计覆盖后复验：`REFERENCE DIALOGUE: 13 checks, 0 failures`。截图人工查看确认居中立绘、姓名牌、徽章、正文与按钮均显示；生成立绘的完整源文件单独保留，游戏对话框覆盖角色下半身是参考布局中的遮挡效果。
