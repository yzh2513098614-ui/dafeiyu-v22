# 海洋遭遇 UI 与紧凑战斗 HUD

地图遭遇提示采用白蓝圆角卡片、蓝色半透明气泡与细描边。角色、怪物插画和原有交互继续从游戏现有系统取用。

- `ui/design/pages/world_encounter_prompt.tscn`：左下遭遇卡，显示当前怪物小像、名称、真实生命/攻击/防御，以及战斗、绕开按钮。
- `ui/design/pages/world_trial_progress.tscn`：右上试炼进度卡；右侧箭头返回港口，通关后显示原有练习入口。
- `ui/design/pages/world_monster_badge.tscn`：跟随怪物投影的名称气泡与可战斗/冷却提示，进入战斗和离开地图时同步隐藏或清理。
- `ui/design/encounter_theme.tres`、`ui/encounter_badge_icon.gd`：共用颜色、描边、按钮状态和原生小符号。
- 地图调查按钮继续使用 `district/map_interactions.gd` 的鼠标/E 键解析路径。

战斗左侧角色卡收为 300×228 设计像素，头像为 64×64；格挡显示为右上图标与数字。生命、体力、连携共用 110×16 进度条与 84px 右对齐数值列。保持现有满值、低值告警、消耗拖尾和恢复提示。

标题栏高 48px，左侧三块面板使用 2px 描边。战报默认显示最近两条记录，闲置 4 秒后降低透明度；点击展开本场完整记录，支持滚动和 Esc 收起。

已在 Godot 4.7.2 的真实地图与战斗界面检查：地图交互 20 项、战斗 HUD 34 项通过。覆盖绕开冷却、E 键调查、战斗入口、返回港口、标签清理、完整日志、五位数格挡、状态图标、资源告警、真实出牌以及战斗随机数不被 UI 操作消耗。
