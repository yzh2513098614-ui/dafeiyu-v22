# 大肥鱼之家 · 小清新地图改造计划

日期：2026-10-14。状态：第一轮改造及反馈修复已完成，详见 `../00_大肥鱼之家小清新改造_20261014.md`。

## 目标与范围

使用 `godot-pastel-diorama` 完善当前游戏中的 `whale_home` 地图，即“大肥鱼之家 · 三层海景宅邸”。主方向采用参考图 1 的奶油薄荷住宅氛围，庭院借用参考图 2 的成簇樱花造型，保留海景宅邸与蓝鲸的辨识度。

本次改造落在现有地图中。保留三层房屋、真实楼梯、楼层切面、鲸鱼家具、水族箱、观星露台、花园码头、角色动作、家具交互、地图连接和存档路径。沿用当前游戏相机与 GL Compatibility 渲染器。

## 执行顺序

| 阶段 | 实际改动 | 完成标准 |
|---|---|---|
| 1. 接入与统一色板 | 备份目标文件；将 skill 的所需组件复制到项目；为建筑与园景增加奶油白、薄荷青、浅草绿、樱花粉色板；调整墙、栏杆、木材及石板颜色，保留鲸鱼主体的蓝色 | 当前地图实际加载项目内的组件；建筑与庭院有一致的配色规则 |
| 2. 完善庭院与步道 | 左侧茶点庭院加入绿树与长椅；右侧蓝鲸花径加入少量樱花树和成簇灌木；前庭整理花坛、草地与奶油石板；部分边界栏杆改为白栅栏造型 | 前庭、左右园景与宅邸有高低层次；门廊、出生点、现有步道与码头出口保持可达 |
| 3. 精修建筑外观 | 保留三层与鲸尾屋冠；完善青灰瓦片、檐口、白窗框及阳台细节；庭院棚顶采用薄荷与奶油色，按空间需要补充局部小瓦棚 | 建筑细节真实建模；保留开放立面、上层切面和观星露台的可见性 |
| 4. 统一日光与海面 | 在本地图内调整暖白太阳、浅蓝绿环境光与日间背景；海面改为柔和蓝绿色及低速波纹；需要时加入少量庭院落花 | 白天柔和、阴影保留体积；既有昼夜和设施灯光继续工作；离开地图后交回原环境控制器 |
| 5. 必要检查与交付 | 做针对性的解析与运行检查；确认地图入口、前庭到码头通路、两段楼梯、楼层切面及家具交互；整理说明并提交本次文件 | 关键路径正常、无本次新增脚本错误；有备份、简短说明与范围明确的提交 |

每阶段形成可用的项目改动，不把所有内容留到最后一次接入。先完成统一色板和庭院，这是与参考风格关联最直接的部分，再精修建筑与环境。

## 具体美术方案

- 建筑：奶油白墙体，青灰檐口，薄荷色局部瓦顶；蓝鲸与星星装饰保留主题色。
- 植物：共享低面数叶团网格；绿树为主要园景，樱花作为前庭和花径的局部焦点。树干分叉与叶团相接，避免一排相同圆球。
- 地面：浅草绿与暖灰、奶油石板分区；顺着已有路径组织植被，避免花盆在通道中连续排成障碍。
- 家具：补充朝向景物的木长椅、花盆与白栅栏，沿用当前茶点庭院和蓝鲸装饰。
- 水与动效：海面使用宽缓色层与少量波纹；落花仅用于室外樱花区域，数量和速度保持克制。

## 接入约束

- 出生点 `Vector3(-9.6, .05, 11.0)` 与返回出口 `Vector3(0, 0, 33.7)` 周围保持通畅。
- 两段现有楼梯和三层支撑结构保留；新屋檐或树冠不改变角色的移动与碰撞尺寸。
- 树干、长椅与围栏按原系统添加或保留必要碰撞；树冠、花瓣不使用大块空气碰撞。
- 新增静态装饰接入既有 `_batch()`，共享网格与有限材质；鱼群、柜门等独立动画对象继续保留。
- 开发运行关闭声音，按项目约定仅做本次所需的功能检查。画面由用户在游戏中检查，不主动扩展为多轮截图或全工程回归。
