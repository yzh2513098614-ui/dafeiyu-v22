# 战斗界面布局重排 · 2026-10-13

此前布局将 gpt6 放在左侧，战报与目标信息横穿战场，手牌被压到右侧大底板里，角色和操作缺少统一空间。本轮保留现有角色、背景、卡牌素材与规则，改为玩家在左、敌人在中右、手牌在底部。

## 实机参考与分析

以下为根据截图进行的布局分析，不是两款游戏的官方设计规范。

- 《崩坏：星穹铁道》：战场是主要视野，角色状态集中在底部，操作位于右下，敌人生命与状态贴近对应单位。参考：[HoYoLAB 实机截图](https://www.hoyolab.com/article/23150695)。
- 《杀戮尖塔》：敌我分居左右，敌人意图贴近敌人；手牌位于底部中央，能量左下、结束回合右下。参考：[Steam 实机截图](https://steamcommunity.com/app/646570/screenshots/)与[官方商店页](https://store.steampowered.com/app/646570/Slay_the_Spire/)。
- 大肥鱼采用卡牌玩法，以《杀戮尖塔》的空间组织为主，同时借鉴《星穹铁道》将信息贴近单位的做法；不增加本作尚不存在的行动序列或技能点系统。

## 已接入的布局

- 左侧展示现有大肥鱼形象、生命、体力、连携、格挡与状态。
- gpt6 和其他敌人位于中右战场，名字、血条与状态贴近脚下，下一步行动显示在立绘上方。
- 手牌回到底部横排，恢复 172×216 的卡面，支持滚动及完整悬停说明。
- 能量位于左下，牌堆与弃牌数量在其下方；目标切换、补给、连携及结束回合在右下。
- 移除卡牌大底板与全宽状态底板，战报收为左上角短条；完整最近记录可悬停读取。
- gpt6 继续使用 2160×3840 透明素材，可见尺寸 349.323×600；相对最初 166.6667×250，宽 2.096 倍、高 2.4 倍。

## 验证与回退

`tools/preview_gpt6_large.gd` 使用 `-- --test-session-ui --test-dialogue`，关闭声音并隔离设置。

实机覆盖 1000×750、1280×720、800×600、gpt6 三目标战斗与普通遭遇；出牌、悬停说明、目标切换、补给/返回、结束回合、演出速度、UI 操作不消耗战斗随机数均通过。结果为 162 条记录，0 失败。
