# 人物统一受光

本轮直接修改 `大肥鱼_数值战斗怪物_v22` 的共享人物渲染代码。

- 取消人物独立自发光。原有 `illustration_fill=0.13` 补光改为真实光源的漫反射补光，与太阳、局部灯光一起接收颜色、距离衰减和遮挡阴影；没有光源时不会产生这项补光。
- 八方向、行走、站立与眨眼使用同一套材质规则。方向校色不再覆盖轮廓强度、宽度或颜色；这些参数只取共享 shader 的默认值，轮廓强度为 `0.28`。
- 比例编辑器清除序列化材质中的旧受光参数，使用当前共享 shader 默认值。受光增益保持 `1.52`，直接光上限保持 `1.10`。
- 地图同伴现有的共享人物 shader 也获得相同改动。
- `tools/preview_character_lighting.gd` 移除手动指定受光参数的前后对比，改为按正常游戏材质捕获昼夜八方向，避免预览与游戏使用不同参数。

画面由用户自行检查。本轮未启动 Godot，未运行预览、截图或测试；这里记录的是代码改动，不代表画面已验收。重新启动游戏加载修改后的脚本与材质。

人物原始图片中已有的明暗仍属于素材本身。地图各自的灯光颜色和强度保留，统一的是人物接收真实环境光的规则。
