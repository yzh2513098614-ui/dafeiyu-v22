## 新台词用法

直接在 `dialogue/stories.json` 的台词节点设置已完成的标记，例如：

```json
{"speaker":"大肥鱼","expression":"shy","text":"谢谢你记得我的名字。"}
```

优先使用默认立绘；在情绪发生变化或开始讲解时换一次。同一情绪连续对白保持同一张，避免逐句闪切。害羞用于亲近回应，担忧用于关心，思考用于分析；斜侧身欢迎用于邀请。轻微不满只用于日常玩笑，不用于严重冲突。

实机截图目录：`预览/对话差分_20261013/`；验证脚本：`tools/preview_dialogue_variants.gd`。

## 接入与验证

对话立绘标记 `runtime_texture`，可编辑 UI 的视觉补丁跳过该控件的 `texture` 属性，其他布局、尺寸、样式照常应用，避免每帧把表情重置为默认立绘。

Godot 4.7.2 实机验证：30 项检查，0 项失败，覆盖八张独立素材的透明通道、实际对白显示、回复选项、对话布局保留和关闭后 HUD 恢复。运行时静音，使用隔离测试存档。

当前世界场景仍报告 `_attach_guide_blink` 延迟回调的对象参数类型错误，人物详情/暂停菜单仍有旧图片加载的导出警告。这些来自本轮未修改的其他模块；本次检查通过只表示对话差分流程通过，不代表全工程无报错或可导出。
