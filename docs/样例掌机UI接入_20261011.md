# 样例掌机 UI 接入

当前启动菜单接入 `ocean-ui-code-demo` 的可编辑原生样式和粉色 / 奶油色 / 薄荷绿背景。外壳、薄荷屏框、粉色立绘框、深色内屏、按钮高光均在引擎内绘制；功能仍由原 `harbor_start.gd` 执行。

- 八个标题入口、8 个出发点、13 个仓储地点、26 张新区地图、设置、音乐鉴赏与继续存档保留。
- 标题按钮沿用蓝白交替，出发按钮加深蓝色；角色沿用 `assets/start/portraits/whale_wave_pixel.png`，保留 alpha 与像素过滤。
- `ui/ocean_sample_skin.gd` 来自样例 `scripts/skin.gd`；`ui/ocean_menu_backdrop.gd` 来自样例 `scripts/backdrop.gd`，补充窗口适配。
- `ui/harbor_menu_skin.gd` 是样例到当前菜单的适配器；`ui/ocean_menu_panel.gd` 和 `ui/ocean_menu_button.gd` 负责装饰边框与高光。
- 现有 `assets/ui/ocean_handheld/source.py` 与 `icons/` 已源于同一 `build_assets.py`，本次直接复用，避免重复资产。
- 启动：双击工程根目录 `开始试玩.cmd`；样例仍可通过其 `launch.cmd` 独立运行。
- 回归：`Godot_v4.7.2-stable_win64.exe --path . --script res://tools/preview_ocean_menu.gd -- --test-session-ui --test-dialogue`；截图目录为 `预览/样例掌机UI接入_20261011/`。
- 回退：本次部署前的实际文件快照与新增文件清单保存至 `备份/20261011_样例掌机UI接入前/`；可以按清单恢复快照、移除本次新增文件。不要恢复用户存档。

本次改动限定启动菜单及其子页，世界场景仍使用游戏自身场景。没有配置可分发的 EXE 导出。

隔离工程实机回归：134 项检查，0 项失败。覆盖 4:3、16:9、小窗口、八个标题入口的布局、出发地与仓储选择、设置保存、音乐播放状态、继续存档、键盘焦点及真实世界启动。
