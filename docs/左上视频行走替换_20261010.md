# 左上方向视频行走素材

已经接入 `assets/character/manifest.json`，版本 10。

随后按用户要求把这套素材水平镜像接入右上方向，当前清单为版本 11。
右上素材位于 `assets/character/up_right_mirror_20261010`，26 个完整 RGBA 帧与遮罩逐像素镜像；站姿、交互、像素密度和受光区域同步对应。
制作脚本 `tools/mirror_up_left_video.py`，实机验证脚本 `tools/check_up_right_mirror.gd` 使用同样的隔离测试参数。
重新制作左上素材后，再执行镜像脚本即可同步更新右上方向。镜像过程保持帧序、alpha 和像素尺寸。

- 原视频：`art_source/up_left_20261010/upLeft.mp4`，1024×768，24 fps，共 158 帧。
- 全部原始 RGB 帧和全部透明帧均保存在该源目录；`.gdignore` 防止把制作中间文件载入游戏。
- 游戏使用源视频第 68–93 帧，共 26 帧；第 94 帧与第 68 帧同相位，因此排除重复端点。
- 站姿和交互使用第 77 帧，保持停步时画风、朝向、尺寸一致。
- 运行素材：`assets/character/up_left_video_20261010/walk_00.png` 至 `walk_25.png`，各自有 `masks` 中的固定 alpha 遮罩。
- 原始人物像素没有缩放：只整帧平移到公共 1024×1152 画布，所有帧统一位移 `(-1,395)`。
- 只按绿幕色抠除背景，头发与鞋腿之间的封闭绿色间隙一起处理；白色头饰、袖口、裙边不参与色键。
- 混色边缘使用 alpha 估计和附近干净原图颜色消除绿色污染；不侵蚀轮廓，不切割关节。
- `pixel_size_by_direction.up_left` 匹配原先的世界高度；方向受光区域按新画布位置校准，只改变光照。
- PNG 导入使用无损模式、尺寸不限、mipmap 开启，自动切换有损 VRAM 压缩关闭。
- 世界移动仍以实际行进距离选择完整画面；原视频提供每一帧姿势。

制作脚本：`tools/import_up_left_video.py --all-frames --install`。重做素材后先运行 Godot `--headless --import --path <工程>`，等待导入结束再运行测试。

实机场景测试：

```powershell
& 'C:\Users\Administrator\Godot\Godot_v4.7.2-stable_win64_console.exe' --path 'D:\迅雷下载\大肥鱼_数值战斗怪物_v22' --script res://tools/check_up_left_video.gd -- --test-merge --capture-ui --capture-dialogue
```

预览和日志：`预览/左上视频替换_20261010`。备份：`备份/20261010_左上视频替换前`。

测试验证 26 个导入帧与遮罩、绿幕残留、尺寸、受光位置、固定根节点、按序选择完整姿势、真实斜向移动与停步站姿，并拍摄街道/室内/夜间画面。其他七方向的资源序列逐项对照备份。
