# 大地图容器存取

F5 进入游戏，在鲸落街区走近货箱、柜子或保险柜，按 **E** 或点击附近的交互按钮打开。

- 点击左侧背包物品，设置数量，点击 **存入容器**；**这一种全存入** 会存入当前可存的整叠。
- 点击右侧容器物品，设置数量，点击 **收进背包**；也可以收取整叠或全部物品。
- 按 **Esc** 合上容器并回到地图；**I** 打开独立背包。
- 每次转移立即保存，切换地图、退出游戏后物品仍属于原容器。空箱不会重新刷补给。

大地图的 38 个容器各有独立 ID 和初始物资，按医疗、物流、海事、设备、单据、餐饮等用途装入已有物品。室内容器和普通补给箱共用双向存取逻辑。两边各最多 64 种物品，每种最多 9999 件；正在装备的最后一件需先卸下，多余副本可直接存入。保存失败会撤回本次转移；隔墙、跨层或离开交互范围不能存取。

界面继续使用项目的糖果色、现有图标和双栏排版。Godot 右侧 **UI 设计** 面板的 **背包 · 容器存取** 对应 `ui/design/pages/inventory_chest.tscn`；可编辑现有按钮、布局和图标。存入/取出按钮的动作随左右物品选择变化。

存档沿用 `user://whale_inventory_v5.json`，数据版本升级到 3，兼容版本 1 和 2。版本 3 会保存存入的新种类、超出原补给数量的存货以及空库存；不清空玩家背包或原有存档。

验证命令（不读写玩家存档）：

```powershell
& "$env:USERPROFILE\Godot\Godot_v4.7.2-stable_win64_console.exe" --headless --path . --script res://tools/test_map_storage.gd -- --test-session-ui --test-dialogue
& "$env:USERPROFILE\Godot\Godot_v4.7.2-stable_win64_console.exe" --headless --path . --script res://tools/test_map_storage.gd -- --test-session-ui --test-dialogue --verify-containers
```

去掉 `--headless` 会输出真实引擎截图。测试将窗口放在屏幕外并避免抢焦点。新进程复验依赖第一条测试生成的隔离存档。`--refresh-container-design` 是维护用参数：会重建该容器设计页和基线，用户已有自定义时请勿使用。
