# 会话框网页计划 · 底部粉色渐变布局

更新：2026-10-15。当前交付入口：[对话网页](dist/index.html#dialogue)，或工程根目录 `网页UI示例.cmd` → 左侧「对话界面」。

## 本轮参考与设计方向

采用半城大人提供的[参考截图](references/dialogue-bottom-layout-20261015.png)。原图是 **1041×163 的底部裁切**，只能确认对白区域和快捷栏的关系；下面的全屏坐标是本项目的设计取值，不是对原作全屏的精确测量。

从参考中采用四个布局关系：

1. 场景和人物连续延伸到画面底部，粉色承面从上向下逐渐显现。
2. 姓名位于正文上方，两者靠同一条左边线；姓名用轻量括号标识。
3. 正文使用暖白字和柔和暗影，背景仍能透出。
4. 常用阅读操作贴近最下沿，以一排小字按钮呈现；自动与快进的选中状态使用薄荷色。

继续复用大肥鱼原有立绘、差分、港口背景和对白内容。截图里的角色、皇冠装饰和右侧视频平台图标不作为项目素材。

## 画布与层级

对话舞台沿用 **1448×815，16:9**，由原预览容器等比缩放。坐标单位均为设计像素。

| 区域 | 当前实现 | 用途 |
| --- | --- | --- |
| 场景背景 | 充满舞台 | 保持原有港口背景，夜色采用紫粉色罩染 |
| 立绘 | 左 449，底 -1，650×780 | 保留原有显示位置、等比缩放及差分淡入 |
| 白天渐变 | 左右 0，底 0，高 264 | 粉色 `rgb(242,153,187)`，顶部透明，向下增强 |
| 夜间渐变 | 同上 | 紫粉 `rgb(116,72,111)`，保持相同结构 |
| 姓名 | 左 240，渐变区顶 +37 | 25 px，暖白字，括号与文字暗影 |
| 正文 | 左 240，渐变区顶 +86，宽 1034 | 默认 30 px，行高 1.78；长文可在区域内滚动 |
| 继续标记 | 右 86，底 83 | 最少 44×44，可补全或推进对白 |
| 章节小标 | 左 55，底 17 | 项目自己的「潮汐手记」标记 |
| 阅读进度 | 左 240，底 23 | 弱化显示章节与当前句数 |
| 快捷操作 | 左 450，右 48，底 10，高 42 | 单行紧凑排列，与正文分开 |

图层顺序：背景 → 立绘 → 选项背景遮罩 → 粉色对白区 → 快捷栏 → 选项 → 回看 / 设置弹层 → 操作提示。

正文和快捷栏分别占据独立区域。渐变装饰层不接收鼠标，隐藏 UI 时连同渐变、姓名、正文和底栏一起隐藏。

## 快捷栏与阅读规则

| 显示 | 功能 | 当前行为 |
| --- | --- | --- |
| Q.SAVE | 快存 | 记住当前对白、分支和回看记录，限本次网页会话 |
| Q.LOAD | 快读 | 回到快存时的对白；没有快存时禁用 |
| LOG | 回看 | 展示已出现对白、玩家选择，可回到指定句 |
| SKIP | 快进 | 连续推进，到选项和本段结尾停止 |
| AUTO | 自动阅读 | 整句显示后等待，再进入下一句 |
| BACK | 上一句 | 回到上一条对白，撤去其后的阅读记录；第一句禁用 |
| NEXT | 补全 / 下一句 | 首次补全当前句，再次推进；选项出现时禁用 |
| CONFIG | 阅读设置 | 调节文字速度、自动等待、字号、渐变浓度 |
| HIDE | 隐藏界面 | 单击画面或按 H 恢复 |

BACK 在进入分支后的第一句会跳过玩家回复记录，回到选择之前的提问，再次展示选项，允许重选。回退会停止自动阅读与快进。

延续键盘操作：Space / Enter 补全或继续，Ctrl 按住快进，A 自动，Q 快存，L 快读，H 隐藏，Esc 关闭弹层。英文菜单配有中文无障碍名称和中文悬停说明。

粉色渐变浓度默认 **82%**，范围 **35–100%**；该值控制整个渐变的强度，不表示全区域都具有相同不透明度。上方仍从透明开始。

## 当前完成与下一步

### 本轮已接入网页

- 通栏粉色渐变、左对齐姓名与正文、暖白文字与暗影。
- 单行英文快捷栏、中文提示、薄荷色选中态、按压和键盘焦点反馈。
- BACK 与 NEXT 接入现有对白状态；原有逐字、自动、快进、分支、回看和快存快读继续使用。
- 旁白、夜色、回复选项、回看及设置采用同一粉紫配色。
- 可编辑源文件、离线单文件和这份布局计划同步交付。

### 下一阶段：依据半城大人的观感反馈细调

只围绕实际反馈调整渐变高度、正文左边距、姓名位置、字号与底栏密度。若反馈正文压住人物或过于靠下，优先调整这几个参数，保持同一套布局关系。保留当前立绘源图与阅读规则。

### 后续功能计划：独立需求确认后实施

- 如果需要普通 SAVE / LOAD，增加有缩略图、章节和时间的存读档弹层，并明确浏览器存储规则。当前只展示已有的 Q.SAVE / Q.LOAD。
- 如果要做专用全屏阅读入口，复用此舞台与状态控制器，单独处理进入和退出；不在当前底栏放置没有行为的 EXIT。
- 网页方向确认后，再将布局拆成 Godot 可编辑 `Control` 页面，接现有 `dialogue_controller.gd` 的对白、分支与存档接口。

本轮交付范围是网页预览。游戏中的对话控制器、角色贴图和存档格式仍由原工程维护。
