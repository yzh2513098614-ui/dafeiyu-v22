# 会话框网页计划 · 底部粉色渐变布局

更新：2026-10-15。当前交付入口：[对话网页](dist/index.html#dialogue)，或工程根目录 `网页UI示例.cmd` → 左侧「对话界面」。

## 本轮参考与设计方向

采用半城大人提供的[参考截图](references/dialogue-bottom-layout-20261015.png)。原图是 **1041×163 的底部裁切**，只能确认对白区域和快捷栏的关系；下面的全屏坐标是本项目的设计取值，不是对原作全屏的精确测量。

从参考中采用四个布局关系：

1. 场景和人物连续延伸到画面底部，粉色承面从上向下逐渐显现。
2. 姓名位于正文上方，两者靠同一条左边线；姓名用轻量括号标识。
3. 正文使用暖白字和柔和暗影，背景仍能透出。
4. 常用阅读操作贴近最下沿，以一排小字按钮呈现；自动与快进的选中状态使用薄荷色。

继续复用大肥鱼原有立绘、差分、港口背景和对白内容。截图里的角色、皇冠装饰和右侧视频平台图标不作为项目素材。

## 快捷栏与阅读规则

| 显示 | 功能 | 当前行为 |
| --- | --- | --- |
| Q.SAVE | 快存 | 记住当前对白、分支和回看记录，限本次网页会话 |
| Q.LOAD | 快读 | 回到快存时的对白；没有快存时禁用 |
| LOG | 回看 | 展示已出现对白、玩家选择，可回到指定句 |
| SKIP | 快进 | 连续推进，到选项和本段结尾停止 |
| AUTO | 自动阅读 | 整句显示后等待，再进入下一句 |
| BACK | 上一句 | 回到上一条对白，撤去其后的阅读记录；第一句禁用 |
| NEXT | 补全 / 下一句 | 首次补全当前句，再次推进；选项出现时禁用 |
| CONFIG | 阅读设置 | 调节文字速度、自动等待、字号、渐变浓度 |
| HIDE | 隐藏界面 | 单击画面或按 H 恢复 |

BACK 在进入分支后的第一句会跳过玩家回复记录，回到选择之前的提问，再次展示选项，允许重选。回退会停止自动阅读与快进。

延续键盘操作：Space / Enter 补全或继续，Ctrl 按住快进，A 自动，Q 快存，L 快读，H 隐藏，Esc 关闭弹层。英文菜单配有中文无障碍名称和中文悬停说明。

粉色渐变浓度默认 **82%**，范围 **35–100%**；该值控制整个渐变的强度，不表示全区域都具有相同不透明度。上方仍从透明开始。

## 半透明图标、细条与待续动效

页面直接进入对白。根据半城大人的明确要求，**不增加素材准备进度、入场加载页或等待遮罩**。

- 快捷操作增加 15 px 线稿图标：常态 48% 不透明度，悬停或选中时升至 90%，禁用时降至 22%。图标沿用按钮颜色，不单独添加实心底板。
- 对白左侧加入低透明度的信封与星芒线稿，作为海风来信主题装饰；不拦截点击。
- 右侧白色细条跟随当前句实际显示字数填充；点击补全时立即填满，下一句重新开始。
- 自动与快进模式在下方增加薄荷色等待细条，与推进计时器使用同一个等待时长；保持原有自动等待设置和选项停顿。
- 不增加独立的循环计时器，图标动效使用 CSS；隐藏和切页使用现有阅读状态暂停。关闭动效或系统要求减少动态效果时，沿用页面现有规则关闭动画。

| 阅读状态 | 右侧小标记 |
| --- | --- |
| 正在出字 | 低透明度圆环，4.8 秒一圈；下方显示省略号 |
| 等待点击 | 圆环与星芒以 1.65 秒周期柔和闪烁，显示 NEXT |
| 自动阅读等待 | 薄荷色，轻转与呼吸，显示 AUTO，并推进等待细条 |
| 快进等待 | 圆环加快旋转，显示 SKIP |
| 回复选择 | 隐藏继续标记与细条，等待玩家选择 |
| 本段结束 | 显示 REPLAY，点击回到开头 |
| 隐藏 / 切页 | 暂停阅读提示动效 |
