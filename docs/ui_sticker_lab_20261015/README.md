# 大肥鱼 · 网页 UI 示例第一版

直接打开 `dist/index.html`，或双击工程根目录的 `网页UI示例.cmd`。当前默认进入 Galgame 对话页，其余页面可从左侧切换。HTML 内嵌字体、图片、图标、样式与脚本，可以离线打开，也可以把这一个文件复制出去预览。

本轮包含三个页面：

- 共用组件：六种按钮状态、贴纸卡片、分类按钮、动效开关、四项数值。右侧可以切换普通 / 满值 / 低值 / 归零；「体力 −12」展示 0.6s 拖尾，「饱食 +20」展示 0.4s 恢复提示。
- 背包与宝箱：12 种项目物品的图标、说明与规则，支持分类、分页、查看详情、使用补给、装备、阅读、收取 / 放入、全部收取和放下确认。可以切换空背包、满背包、空宝箱；满背包可叠加已有物品，新物品需要空格。
- 对话：16:9 舞台、现有角色立绘与港口背景、逐字显示、旁白、三种分支与表情切换，支持自动阅读、持续快进、快存 / 快读、对白回看和回退、隐藏界面与阅读设置。

组件与背包的示例画布为 1448×1086，对话页为 1448×815（16:9），网页按窗口宽度等比缩放。左侧切页，右侧切状态与晴日 / 夜色背景。所有操作使用页面内模拟数据；刷新或点击「复原示例」恢复初始状态。

## Galgame 对话完善 · 2026-10-15

以舞台、立绘、文本框、姓名栏、选择菜单和回看组成阅读界面，结构参考 [Ren'Py GUI 文档](https://www.renpy.org/doc/html/gui.html#dialogue)，视觉继续沿用项目的白包边和蓝色硬底影。

- 16:9 对话舞台降低底部文本框高度，把角色留在画面中心；顶部只保留章节提示，探索 HUD 在对话页隐藏。文字居于文本框中央，姓名条浮在左上，快捷菜单独立放在底部。
- 保留完整立绘源图，只在网页中等比显示；新增复用说话、害羞差分，随对白淡入切换。旁白降低立绘亮度，并使用独立的姓名 / 正文字色。
- 正文逐字出现，标点有短暂停顿；首次点击补全，下一次点击才推进。自动阅读等待整句显示完，持续快进在选项与本段结尾停止。
- 示例包含六句开场、三种回复及各自的后续对白。回看保留玩家选择，并可回到某句重新选择后续。
- 「快存 / 快读」记住当前示例的对白、分支和回看记录；仅保存在当前网页会话，刷新即清除。
- 阅读设置可调整文字速度、自动等待、字号和文本框承面透明度；隐藏界面后可单击画面或按 H 恢复。
- 键盘：Space / Enter 补全或继续；Ctrl 按住快进；A 自动；Q 快存；L 快读；H 隐藏；Esc 关闭弹窗。F5 保留浏览器刷新功能。
