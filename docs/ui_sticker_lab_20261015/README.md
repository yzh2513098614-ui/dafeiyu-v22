# 大肥鱼 · 潮汐手记网页 UI

直接打开 `dist/index.html`，或双击工程根目录的 `网页UI示例.cmd`。当前默认进入 Galgame 对话页，其余页面可从左侧切换。HTML 内嵌字体、图片、图标、样式与脚本，可以离线打开，也可以把这一个文件复制出去预览。

当前会话框采用参考截图中的底部粉色渐变布局，左上章节信息使用粉白便签、独立编号与星形书签：[打开对话](dist/index.html#dialogue)。尺寸、功能范围和后续步骤见[会话框网页计划](会话框网页计划.md)。

背包、共用组件与外层导航采用**蓝白厚边框与糖果色副色**：[打开背包与宝箱](dist/index.html#inventory) · [打开共用组件](dist/index.html#components)。厚白包边、浅蓝内框和蓝色底座保持主结构；青色、暖黄、粉色与淡紫用于分类、局部承面和装饰。对话界面保留原有粉色设计。规格见[背包与共用组件计划](背包与共用组件计划.md)。

本轮包含三个页面：

- 共用组件：六种按钮状态、厚白框状态卡、分类按钮、动效开关、四项数值。右侧可以切换普通 / 满值 / 低值 / 归零；「体力 −12」展示 0.6s 拖尾，「饱食 +20」展示 0.4s 恢复提示。
- 背包与宝箱：12 种项目物品的图标、说明与规则，支持分类、分页、查看详情、使用补给、装备、阅读、收取 / 放入、全部收取和放下确认。可以切换空背包、满背包、空宝箱；满背包可叠加已有物品，新物品需要空格。
- 对话：16:9 舞台、现有角色立绘与港口背景、逐字显示、旁白、三种分支与表情切换，支持自动阅读、持续快进、快存 / 快读、对白回看和回退、隐藏界面与阅读设置。

组件与背包的示例画布为 1448×1086，对话页为 1448×815（16:9），网页按窗口宽度等比缩放。左侧切页，右侧切状态与晴日 / 夜色背景。所有操作使用页面内模拟数据；刷新或点击「复原示例」恢复初始状态。

背包与共用组件回到蓝白贴纸结构，强调厚白边、内框和蓝色硬底影；[对话参考截图](references/dialogue-bottom-layout-20261015.png)对应的粉色设计仅用于对话舞台。数值语义继续沿用 `candy-sticker-vitals/references/mockup-v3.html`：生命低值使用红色警报，其他低值使用暖黄 / 棕色，归零保留灰色虚线。会话框规格见[会话框网页计划](会话框网页计划.md)。

素材原样复用项目资源，索引见 `asset-manifest.json`。没有修改 Godot 场景、游戏脚本、平衡数据或存档。对话正文是此次编写的预览文案。
