# 背包与共用组件 · 潮汐手记样式

更新：2026-10-15。

入口：[背包与宝箱](dist/index.html#inventory) · [共用组件](dist/index.html#components)。根目录 `网页UI示例.cmd` 也可进入，使用左侧切页。

## 本轮方向

延续已确认的[会话框设计](会话框网页计划.md)：粉紫半透明承面、暖色正文、低透明度线稿图标、薄荷色选中提示与轻柔闪烁。背包继续保留收纳盒的分层厚度。

复用原有物品图片、物品描述、数值、分类与交互。两页仍使用 **1448×1086** 等比画布，对话页保持自己的 16:9 舞台。

## 背包落地

- 外壳仍位于 `(54,104)`，尺寸 `1340×920`；白边 5 px，分层底边约 12 px。
- 左侧使用收纳区，右侧维持 338 px 详情卡。单背包显示 5×4 格，宝箱模式两侧各 3×4 格。
- 粉色收纳槽与薄荷宝箱槽区分来源；物品卡保留凸起底边、按压下沉与选中勾选。
- 选中卡片角点和物品档案标记柔和闪烁；收纳细条按已占用格数 / 64 更新，满包使用暖黄色提示。
- 详情保留物品图、持有数量、用途、说明、装备标记、主操作和放下确认；长说明继续在卡片内滚动。

## 共用组件落地

- 在同一块半透明面板内排列标题、按钮与数值、卡片与开关、底部提示。
- 六种按钮反馈保留普通、悬停、按下、选中、焦点与禁用；选中使用薄荷承面，禁用弱化对比。
- 四项数值保留满值「满」、生命低值红色、其余低值暖黄、归零灰色虚线，以及原有拖尾和恢复闪头。
- 低值读数增加浅色承面，保证深紫背景下仍可辨认；静态装饰不承担告警含义。
- 动效开关继续统一控制所有页面；系统的减少动态效果偏好也沿用现有规则。

## 范围与文件

`gal-system.css` 负责组件、主题与共用控件；`inventory.css` 负责背包布局与状态。`index.template.html` 增加可编辑线稿与组件区块，`ui.js` 复用相同符号，`build_preview.py` 打包新增样式。

当前直接进入所选页面，不增加素材准备进度或入场加载页。本轮更新网页预览，游戏内数据和存档由原工程继续维护。
