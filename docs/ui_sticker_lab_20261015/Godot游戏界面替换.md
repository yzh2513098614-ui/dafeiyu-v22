# 正式游戏 UI 迁移 · 2026-10-16

网页方案已接入实际游戏。正常启动后，按 `I` 打开背包、靠近原有容器交互、按 `Q` 与大肥鱼聊天，都使用新的 Godot 界面。

## 背包、宝箱与共用组件

背包为五列四行物品格，保留分类、搜索、排序、分页、右侧详情、使用、装备、收藏和容量条。宝箱为左右两个三列四行收纳区，保留真实数量选择、取出、存入和整组转移。容量、距离、最后一件装备保护、自动保存及失败回滚继续由 `loot_controller.gd` 处理。

共用主题为 `ui/design/sticker_shared_theme.tres`，在 Godot 中直接编辑。沿用共用皮肤的菜单、面板和按钮切换为蓝白主色、厚白边与蓝色底边，青粉紫黄作为副色；面板加入圆角渐变块。贴纸按钮与键盘焦点采用单圈边缘，原有四项数值告警语义和拖尾逻辑继续沿用。

## 对话界面

`dialogue/gal_view.gd` 绘制原生 Control 界面，`dialogue/dialogue_controller.gd` 继续处理真实剧情、分支、立绘差分、路线和持久存档。场景继续显示实际游戏地图，立绘居中；粉色渐变延伸到底部，姓名与正文左对齐。左上章节便签含编号、地点和星形书签；夜间切换为紫粉色。

底栏包含 Q.SAVE、Q.LOAD、LOG、SKIP、AUTO、BACK、NEXT、CONFIG、HIDE。快存快读保存在原对白存档中；BACK 和快读恢复节点、分支标记、回看及路线。带节点记录的回看可以跳转，旧回看记录仍可阅读。快进在选项处停下，结束当前剧情后返回游戏。

阅读设置包含文字速度、自动等待、字号、渐变浓度与提示动效，并写入对白存档。隐藏、设置和回看会暂停阅读。右侧提示与细条跟随实际出字和等待状态；装饰忽略鼠标。没有新增入场素材准备页。

Space / Enter / E 补全或推进，数字键选择，A 自动，按住 Ctrl 快进，Q 快存，L 快读，H 隐藏或恢复，Esc 关闭弹层或返回游戏。Tab 和方向键交给原生控件；工具栏获得焦点时，Enter / Space 执行该按钮。

## 原生编辑与文件

新设计页为 `ui/design/pages/inventory_*_sticker.tscn` 和 `ui/design/pages/dialogue_gal*.tscn`。对应基线与设计页同时生成，运行时由 `ui/design/design_runtime.gd` 使用新 ID 应用视觉改动。原背包和对话设计页、基线保留。

背包皮肤：`ui/harbor_inventory_skin.gd`；物品格：`ui/inventory_slot.gd`。渐变着色器与线性 SVG 图标：`assets/ui/sticker/`。共用主题的显式重建工具：`tools/build_sticker_shared_theme.gd`，重新生成会覆盖该主题的手工修改。

## 查看与验证

双击根目录 `Godot界面预览.cmd` 查看真实背包，`Godot对话预览.cmd` 查看真实对话。两个窗口使用隔离测试存档并默认静音；正常游戏使用自己的存档。预览入口直接显示界面。

背包和宝箱的 24 项定向检查通过，对话的 30 项定向检查通过。检查包含实际控制器回调、物品交易守恒、使用后角色数值、自动保存、分支重选、快存快读、路线恢复、阅读暂停和可编辑页面安装。源文件也通过针对性 GDScript 加载检查。

实际截图、检查 JSON 和运行日志分别位于 `预览/正式背包贴纸_20261016/`、`预览/正式对话迁移_20261016/`。运行入口为 `tools/preview_sticker_inventory.gd` 和 `tools/preview_gal_dialogue.gd`；重建原生页面使用 `--bake-sticker-designs` / `--bake-gal-designs`，不会由普通预览启动器自动覆盖。

## 章节卡细化 · 2026-10-16

章节便签改为 336×142，标题使用更醒目的粗字重并允许最多两行，地点行提高到 13 px。编号改为轻薄矩形标签，移除其厚底影；右上星形书签改为燕尾形。保留粉白渐变和夜间紫粉配色，同步四个原生设计页，基线与阅读状态逻辑保持原样。

同时修正 `ui/design/layout_document.gd` 对新增材质与空资源进行比较时的类型错误，使原生页面新增材质能正确应用。

## 设置界面迭代 · 2026-10-16

正式游戏设置的三个页签采用蓝白外壳、单层边缘和青粉紫黄渐变副色。声音页将背景音乐与游戏音效分别收进完整控制卡，开关、说明、滑块和百分比在同一组；配乐风格改为通栏选择卡。画面页保留七个开关和一天长度，音效试听保留全部分类、单项和整类试听与停止入口。

底部提供自动保存提示与完成按钮。共用滑块使用白色蓝边圆形把手、青色 / 紫色细条和浅蓝轨道。真实设置、播放、音量与自动保存回调继续沿用，配置路径不变。

原生编辑页为 `ui/design/pages/settings_display_sticker.tscn`、`settings_audio_sticker.tscn`、`settings_audition_sticker.tscn`；旧设计页与基线保留。双击根目录 `Godot设置预览.cmd` 可打开实际设置，使用隔离配置和静音预览。正常游戏从原设置入口打开。

预览与必要回调检查入口：`tools/preview_sticker_settings.gd`；记录在 `预览/正式设置迭代_20261016/`。首次创建原生页面使用 `--bake-settings-designs`，已有基线不会被重写。

设置页的 10 项定向检查通过，覆盖真实音量滑块、音乐开关与禁用状态、配乐风格、画面偏好、隔离配置自动保存、三页切换和关闭返回；三个原生页面加载通过。检查日志为 `预览/正式设置迭代_20261016/verify.log`。
