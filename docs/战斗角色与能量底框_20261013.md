# 战斗角色与能量底框 · 2026-10-13

用户要求为左侧角色、属性、能量与牌堆数制作底框及 UI。应用 game-ui 技能，使用 Godot 原生 Panel 与 StyleBoxFlat 接入现有实时控件。

## 共享视觉规格

- 配色：沿用 ocean-soda 海盐汽水；外框蓝紫 #B5C4E9，头像水蓝 #DBEAFD，属性与资源内框 #D9E3FA，正文深蓝 #293F52。
- 结构：角色头像、名字、格挡与生命/体力/连携统一收入角色状态卡；能量与牌堆/弃牌统一收入左下资源卡。
- 边界：主框 3px 深蓝描边、24px 圆角、轻阴影；内框 1px 细边、12px 圆角。
- 层级：生命粉色、体力薄荷、连携蓝紫、能量黄色；平静底板承载文字，强调色用于资源与状态。
- 字体：底板内使用深色字，去掉依赖背景描边的悬浮字；深色能量球保留浅色说明和黄色数值。
- 素材：复用原角色、图标与 4K gpt6，不生成新图标。

验证脚本：tools/preview_gpt6_large.gd，参数 -- --test-session-ui --test-dialogue。

改动前备份：备份/20261013_角色与能量底框前/。

## 实机结果

- 1000×750、1280×720、800×600、三目标与普通遭遇检查通过；189 条记录，0 失败。
- 头像、角色名和属性数值均位于对应底框内；能量与牌堆/弃牌均位于资源卡内。
- 五位数格挡与三个状态图标不重叠；出牌、悬停说明、补给返回、目标选择与结束回合正常。
