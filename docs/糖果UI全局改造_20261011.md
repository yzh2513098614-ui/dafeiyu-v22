# 战斗与已接入界面统一改造

按 game-ui 技能构建原创的蓝紫、薄荷青、莓果粉休闲游戏界面。截图参考只用于理解功能关系；新界面由 Godot 原生 Control、Theme、StyleBoxFlat 绘制，统一字体、圆角、深色边框、按钮状态与浅色高光。

## 当前接入范围

- 战斗：整条标题栏、回合与阶段提示、敌人铭牌/生命/格挡、战报和目标、水平能量与操作工具栏、手牌分类色框、完整卡牌悬停说明、补给列表、角色及三个独立状态卡、胜负结算。
- 主菜单与已接入的世界 UI：标题、出发地点、设置、音乐相关菜单、探索 HUD、暂停、对话、选项和回看。
- 宝箱与背包：继续使用双栏容器与物品网格，全部面板和按钮改为同一套皮肤。
- 远征控制器通过现有 whale_skin 适配器继承共享皮肤；本次实机验证集中在鲸落港主流程与卡牌战斗。

人物、怪物、港湾像素背景、42 张卡牌插画与既有原创功能图标继续沿用工程资源。本次不修改战斗引擎、卡牌数值、背包事务或玩家存档路径。旧绘制素材保留在资源目录中。

## 维护入口

`ui/candy_skin.gd` 是颜色、面板和按钮状态的共享源。`handheld_skin.gd`、`harbor_menu_skin.gd`、`harbor_inventory_skin.gd`、`battle_skin.gd` 保持原调用接口，接到共享皮肤。战斗旧边框调用由 `battle/candy_ui_assets.gd` 转为原生面板，并保留动态生命条颜色的 StyleBox 实例。

设计画布仍是 1448 × 1086。战斗能量、补给、连携、目标、结束回合在手牌上方；手牌区和底部状态区之间保留至少 20 个设计像素。手牌多于一屏时保留滚动条及键盘焦点跟随。悬停说明独立放在战场右侧，移除了遮挡卡牌的重复 tooltip。
