# 宝箱与随身背包

参考图只用于双栏格子、物品说明与底部操作区的排版。参考图没有进入游戏资源。
使用 `game-ui` 规格：糖果色扁平卡通、深紫圆角描边、清楚色块、单层阴影与顶边高光。
配色沿用现有掌机：蓝紫 `#6469DF`、薄荷绿 `#7ADCC4`、粉色 `#F48BB7`；界面承载色为蓝紫和海蓝色。
没有采用奶油白主题。物品继续使用原工程图像，新增宝箱图标为原创可编辑 SVG。

## 使用

- 走近港口或室内的补给箱，按 `E` 打开。左侧为当前随身背包，右侧为当前箱子。
- 点击右侧物品，选择数量，点击“收进背包”或“这一种全收取”。
- “全部收取”一次收取能装下的所有物品。优先补齐已有堆叠，装不下的仍保留在箱内。
- 按 `I` 打开背包。支持分类、名称/用途/故事搜索、排序、分页、收藏、补给使用、装备与卸下。
- `Esc` 关闭；背包再次按 `I` 也可关闭。打开界面时继续沿用原游戏的移动与时间阻塞。

容量沿用 64 种物品，每种上限 9999。取物、人物效果和存档继续使用原事务逻辑。
整箱收取会将背包与箱子库存作为一次保存提交；保存失败时两者一并恢复。旧存档路径与格式保持兼容。
新区搜打撤与实验远征拥有独立容量、撤离/保险及仓库机制，本次改动接入港口生活背包与其全部容器。

## 文件

| 文件 | 作用 |
|---|---|
| `loot_controller.gd` | 存取事务、整箱收取、容量检查、装备状态、模态入口 |
| `ui/bag_view.gd` | 背包分类、搜索、分页、详情和操作 |
| `ui/chest_view.gd` | 双栏箱子与背包、数量、收取与反馈 |
| `ui/harbor_inventory_skin.gd` | 共享配色、原生面板与按钮、容量条 |
| `ui/inventory_slot.gd` | 格子、堆叠数、收藏与装备标记 |
| `assets/ui/inventory/chest.svg` | 原创宝箱图标，128×128，透明底 |
| `tools/preview_chest_bag.gd` | 使用隔离存档的真实输入与引擎截图检查 |

新 UI 使用 Godot 原生可交互控件，图标为现有素材及 SVG；没有使用整张生成图作界面。
新宝箱图标可在 `32/48/64 px` 下使用，线性过滤，透明边缘。其造型、轮廓和配色由本次代码直接制作。
