1. **体积主要由三代内容构成**：`预览\`（794 MB，近乎逐帧截图）+ `art_source\`（523 MB，原始生成源）+ `assets\character\`（313 MB，v20–v24 五代并存）。若需要瘦身，优先处理 `预览\攻击反馈_v22\`（454 MB 截图）与 `assets\character\jimeng_v20`–`v22` 旧版。
2. **两处 zip 与解包内容重复**：`素材包\大肥鱼_v22_内墙外墙纹理12套.zip`（11.9 MB）与 `大肥鱼_城镇物品与植物_24件3D模型.zip`（9.6 MB）都已解包进 `assets\` / `models\`，zip 仅作交付留档。
3. **`world_pack26\interior_pack\` 是 `interior_pack\` 的超集**（2602 vs 764 文件），26 地图接入时复制了一份；`NotoSansSC.ttf` 随包复制了 3 份。若要合并需先确认 `world_pack26` 内 `library_173` 等额外目录的引用关系。
4. **跑图/脚本产物未清理**：`tools\video_runtime\`(212 MB) 与 `.mcp\godot-runtime\`(93 MB) 属工具链，`.godot\`(621 MB) 可随时删除重建；根目录 8 个 `.log`（合计 ~380 KB，最大 `character_8dir_capture_v23.log` 65.7 KB）为历史验证日志。
5. **素材索引的语义信息未被新清单覆盖**：旧 CSV 里的「碰撞宽高 / 层级 / SHA256」是当前素材系统真正依赖的字段，本次清点只做文件层面统计，两者应并存而非替代。
