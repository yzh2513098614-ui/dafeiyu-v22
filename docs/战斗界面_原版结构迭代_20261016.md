# 战斗界面：在原版结构上迭代

本轮使用 `game-ui` 技能，按已确认的六项改进方案建立“敌方意图 → 可打手牌 → 回合行动”的阅读顺序。保留少量深色轮廓与原版左侧状态卡、中央立绘、底部手牌、右侧行动布局。样式已经接入正式 `battle/battle_screen.gd`；独立试玩也直接实例化正式界面与真实战斗引擎。

## 视觉规格

- 背景层：保留港湾背景和完整的敌人展示与点击区域；低透明冷色罩轻压背景对比，战场大框继续隐藏。
- 容器层：312×520 玩家状态卡、标题、战报与底部手牌底座采用 2px 深灰蓝边缘 `#40567d`，配轻量底影。内部色块取消重复边框和底影。
- 渐变层：方向统一为左上亮、右下稍深，主要容器保留适度渐变，内部色块降低渐变强度。颜色来自原生 StyleBox，可在设计器查看。
- 敌方信息：姓名、生命数值、生命条、行动图标与下一次行动合为脚下的同一组铭牌，意图文字使用深色正文，取消头顶分散的意图文字。
- 玩家信息：鲸鱼头像为 156×156；生命采用更大读数与更厚槽体，格挡保留独立数值，体力与连携使用较小字号、较细槽体和较弱颜色。三项状态以无边框色块分层。
- 手牌层：手牌为 182×222，插画占卡牌高度 50%；费用、名称、插画、效果形成固定读序。效果数值加粗放大，说明文字退一级，外侧保留 2px 深灰蓝轮廓。
- 手牌状态：悬停与键盘焦点会轻微抬起卡牌并加强轮廓；滚动区预留抬起空间。费用不足时保留文字可读性、弱化插画并显示“能量不足”，使用引擎的真实可用状态。
- 行动层：切换目标、补给、连携采用安静浅色承面；结束回合加高、使用更完整的青色并留出间隔。按钮统一图标尺寸与间距，保留 2px 深色外边缘。
- 按钮保留正常、悬停、按下、焦点、禁用状态；悬停卡牌继续显示完整原插画与说明。

## 文件与入口

- `ui/design/pages/battle.tscn`：同步标题、回合、玩家状态卡及内层面板的原生可编辑样式。
- `battle/battle_screen.gd`：正式战斗面板、运行时资源框、敌人铭牌与行动按钮样式。
- `battle/card_face.gd`：动态生成的手牌与放大预览样式。
- `battle/layered_panel.gd`：原生圆角渐变块，不额外绘制内线，不增加输入遮罩或节点层级。
- `battle/battle_veil.gdshader`：港湾背景的低透明冷色罩。
- `battle/layered_button.gd`：轻量表面高光；单层描边、文字、图标和输入由 Button 绘制与处理。
- `tools/preview_battle_original.tscn`：原版结构试玩入口；目标、出牌、补给和结束回合使用正式逻辑。

从工程目录运行隔离试玩：

```powershell
& "$env:USERPROFILE\Godot\Godot_v4.7.2-stable_win64_console.exe" --audio-driver Dummy --path . res://tools/preview_battle_original.tscn -- --test-session-ui --test-dialogue
```

该入口使用固定的示例敌人与手牌种子，不加载或保存玩家进度。正式游戏内的战斗自动使用本轮样式。

## 验证

Godot 4.7.2、GL Compatibility，1280×720 的真实渲染运行中，以鼠标输入执行检查：

- 正式界面加载设计页样式，左侧状态卡、中央立绘与下方手牌保持原版相对位置。
- 确认新增战场大框已隐藏且不拦截输入；手牌区完整位于底座内；四个行动按钮位于行动区域内且不重叠。
- 确认敌方意图与生命条位于同一铭牌内；能量不足时卡牌禁用并显示原因。
- 八张手牌滚动时底部不被滚动条遮挡，键盘焦点能够滚动到后面的牌。
- 卡牌悬停抬起时仍位于预留区域内；受检攻击牌的效果正文没有纵向裁切。
- 点击立绘与目标按钮切换真实目标。
- 补给菜单打开与返回；这些界面动作不消耗战斗随机数。
- 卡牌悬停打开完整预览，点击出牌减少手牌并伤害所选敌人。
- 结束回合通过正式引擎结算，回到可操作状态。

结果：`ORIGINAL BATTLE UI: 19 checks, 0 failures`。运行使用 Dummy 音频驱动并关闭 BGM/SFX，无 GDScript 运行错误；退出时出现 `2 ObjectDB instances were leaked at exit` 清理警告。未做截图审美验收或多分辨率巡检，画面效果由用户自行检查。
