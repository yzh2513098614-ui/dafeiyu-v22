# 战斗界面：在原版结构上迭代

本轮使用 `game-ui` 与 `candy-sticker-game-ui` 技能，根据“全部都要改，要分层、加框、加渐变块”的反馈，继续沿用原版的左侧鲸鱼状态卡、中央大立绘、底部插画手牌与右侧行动按钮。样式已经接入正式 `battle/battle_screen.gd`；独立试玩也直接实例化正式界面与真实战斗引擎。

## 视觉规格

- 背景层：保留港湾背景，透明的战场框在立绘后方，保留完整的敌人展示与点击区域。
- 容器层：独立的战场外框、312×520 玩家状态卡、底部手牌底座与行动内框。白色外包边、蓝色硬边底影 `#638eff`、内侧细线明确区分边界。
- 渐变层：标题、回合、战报、状态卡、头像框、资源区、行动底座均使用由浅到深的圆角渐变块；颜色来自原生 StyleBox，可在设计器查看。
- 内容层：鲸鱼头像缩至 180×188，三项状态各有内框，玩家状态卡与中央立绘分离。战报恢复标题与多行区域。
- 手牌层：手牌扩大到 182×232；每张牌分别具有外框、渐变标题带、费用圆贴、插画内框、渐变效果块。插画继续使用原素材。
- 行动层：切换目标、补给、连携位于内框上部，结束回合加高并与次要行动留出间隔。文字 `#31547e`，浅蓝紫为主要承面，青色用于主行动。
- 按钮保留正常、悬停、按下、焦点、禁用状态及内线；悬停卡牌继续显示完整原插画与说明。

## 文件与入口

- `ui/design/pages/battle.tscn`：同步标题、回合、玩家状态卡及内层面板的原生可编辑样式。
- `battle/battle_screen.gd`：正式战斗面板、运行时资源框、敌人铭牌与行动按钮样式。
- `battle/card_face.gd`：动态生成的手牌与放大预览样式。
- `battle/layered_panel.gd`：原生圆角渐变块、内线与高光，不增加输入遮罩或节点层级。
- `battle/layered_button.gd`：原生按钮内线与高光，文字、图标和输入仍由 Button 绘制与处理。
- `tools/preview_battle_original.tscn`：原版结构试玩入口；目标、出牌、补给和结束回合使用正式逻辑。

从工程目录运行隔离试玩：

```powershell
& "$env:USERPROFILE\Godot\Godot_v4.7.2-stable_win64_console.exe" --audio-driver Dummy --path . res://tools/preview_battle_original.tscn -- --test-session-ui --test-dialogue
```

该入口使用固定的示例敌人与手牌种子，不加载或保存玩家进度。正式游戏内的战斗自动使用本轮样式。

## 验证

Godot 4.7.2、GL Compatibility，1280×720 的真实渲染运行中，以鼠标输入执行检查：

- 正式界面加载设计页样式，左侧状态卡、中央立绘与下方手牌保持原版相对位置。
- 渐变战场框位于可点击立绘后方；手牌区完整位于外框内；四个行动按钮完整位于内框内且不重叠。
- 点击立绘与目标按钮切换真实目标。
- 补给菜单打开与返回；这些界面动作不消耗战斗随机数。
- 卡牌悬停打开完整预览，点击出牌减少手牌并伤害所选敌人。
- 结束回合通过正式引擎结算，回到可操作状态。

结果：`ORIGINAL BATTLE UI: 13 checks, 0 failures`。运行使用 Dummy 音频驱动并关闭 BGM/SFX，无 GDScript 运行错误；退出时出现 `2 ObjectDB instances were leaked at exit` 清理警告。未做截图审美验收或多分辨率巡检，画面效果由用户自行检查。
