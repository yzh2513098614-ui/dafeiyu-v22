# 广西医科大学武鸣校区 · v07 屋顶细化

本轮继续使用用户提供的教学楼、独立钟楼、双塔及图书馆照片。
**钟楼与教学楼仍然是两栋独立建筑，分别选中和编辑。**
压缩包沿用原工程文件名以延续工程，当前内容为 v07。

## 本轮屋顶

| 建筑 | 对照照片的修改 |
| --- | --- |
| 教学楼 | 低坡灰瓦四坡屋面，瓦片逐坡裁切、交错分排；增加分段主脊和斜脊、真实檐边厚度、封闭檐底、两道石材檐口、开口雨槽和后角雨管 |
| 教学楼中央 | 浅色板与连续竖向构件高出前檐，补顶部压边，修正此前抬高构件过低的轮廓 |
| 庭院楼翼 | 保留平屋面，补女儿墙顶部金属压边、内侧泛水和屋面分缝 |
| 独立钟楼 | 下段绿色屋顶改为真正的截顶四坡壳体；收腰处为深色细分格，再接独立的上段陡尖顶；补折边、板缝、水平搭接和尖端小构件 |
| 双塔 | 三段逐级抬高的弧形金属冠顶，补曲面壳体厚度、四分之一弧形端部、折边接缝、曲边梁、檐边和底部细梁 |
| 图书馆 | 环形凸弧金属屋面采用平滑法线；补径向折边接缝、内外连续卷边、屋檐下深色窗带与细白柱，保留中央露天庭院 |

屋顶、瓦片、屋脊、接缝和檐口都是真实三维几何，不是整张照片贴片。
瓦片尺寸、坡度、板材宽度、檐口厚度及各楼高度均按可见比例估计，尚无实测尺寸。
照片教学楼的实际编号仍未确认；独立照片模型不等同于已确认的 A9。

## 打开与查看

1. Godot 4.6.2 打开 `GXMU_Wuming_Godot_2_5D/project.godot`，等待资源导入，按 F5。
2. 按 **O** 进入屋顶近景；**1/2/3/4** 分别看教学楼、独立钟楼、双塔、图书馆。
3. 近景内滚轮缩放，Q/E 旋转，H 隐藏面板，Esc 返回校园。
4. 按 P 看教学楼与独立钟楼，1 看两栋及空地、2 看教学楼正面、3 看钟楼。
5. 校园内 C 看教学楼，J 看独立钟楼，T 看双塔，B 看图书馆。

也可直接打开 `wuming_campus/scenes/world/photo_roof_detail.tscn` 后 F6。

## 场景与源码

- 教学楼：`scenes/buildings/photo_teaching_wing.tscn`。
- 独立钟楼：`scenes/props/clocktower.tscn`。
- 双塔：A10、A11；图书馆：B1。
- 两栋关系近景：`scenes/world/photo_teaching_detail.tscn`；两栋为不同根节点。
- 屋顶查看场景：`scenes/world/photo_roof_detail.tscn`。
- `authoring/roof_detail_v07.py`：本轮屋顶壳体、瓦面、压脊、雨槽、曲面与接缝。
- `authoring/refine_roofs_v07.py`：只更新屋顶涉及的模型，不重算全校布局。
- `authoring/architecture_v06.py`：教学楼分区、窗组、深凹走廊与中央竖板。
- `authoring/landmark_detail_v06.py`：双塔及图书馆结构。
- `authoring/photo_refinement.py`：独立钟楼、校训门及景观。
- `data/photo_roof_basis.json`：本轮照片依据及估算边界。

依赖见 `authoring/requirements.txt`。重建屋顶 GLB 使用：
`python3 authoring/refine_roofs_v07.py`。
只改双塔时可加 `--assets A10 A11`。然后在 Godot 导入并执行
`res://wuming_campus/tools/bake_campus.gd`，再执行 `make_photo_detail.gd` 和
`make_roof_detail.gd`。包内原生场景已经生成，不必重建即可使用。

共有 118 个模型资源，分类索引在 `docs/资源分类索引.md`。
复制整个 `wuming_campus` 目录到原游戏工程时保留目录名和内部路径。
