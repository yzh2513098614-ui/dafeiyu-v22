# 大肥鱼 · 完整图片人物 v16

本版使用用户已经选定的完整人物 PNG 图集，四方向各六帧，共二十四帧。人物保持原图中的完整头发、裙摆、鲸尾、超短腿和鞋。整套新动作重绘尚未形成合格素材，本版交付的是这套已选定原图的稳定接入与定位修正。

主入口为 `district/continuous_world.tscn`。Windows 双击「启动完整图片人物.bat」，或使用 Godot 4.6.2 打开 `project.godot` 运行。详见「00_完整图片人物使用说明.md」。

图片统一为 512×512 画布，人物根点固定为 `(256,420)`。同一方向只做一次统一比例和中心定位，所有帧共用该方向的根点；不会随着每帧最低像素改变整个人物高度。游戏依据真实位移切换行走帧，松开方向键或被墙堵住时停步。

空间保留一张连续街区，十二栋大小不同、错位排列的建筑。云湾公寓、潮汐社区馆、海风旅舍分别有三、二、三层，每层同时展示六个大小不同的房间、门洞和连接通道。WASD / 方向键行走，E 进出建筑或使用楼梯、电梯，Z 切换总览和人物跟随，滚轮缩放，M 导览。

实机预览位于「预览/完整图片人物_v16」，由生产游戏控制器和实际碰撞生成，使用固定物理时间记录。空间截图保留在「预览/连续大地图_v13」。动作研究保存在「人物动作_联网研究与重做规格.md」，其中重绘计划属于后续制作方向。

已完成的去多余耳鳍、淡色和重画眼睛单人基准，原 PNG 与完整提示词保存在「美术参考」目录，供后续动作绘制使用。
