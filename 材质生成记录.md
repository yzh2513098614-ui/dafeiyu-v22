# v6 像素材质生成记录

使用 **内置 imagegen 工具**，参考用户提供的像素雪地场景，取其表面颗粒、冷暖对比与细节层次，生成一张 3×3 材质图集。随后通过 Godot 原生 Image.get_region / resize 提取 9 张材质，保存为 assets/materials/*.png。参考图没有作为房间背景或原始贴图直接使用。

原始生成图：assets/materials/material_atlas_source.png。裁切程序：tools/build_materials.gd。

## 完整提示词

Use case: stylized-concept. Asset type: a square 3x3 GRID MATERIAL ATLAS for an actual Godot 2.5D pixel RPG, not a scene illustration. Input image is ONLY a reference for richly tactile, hand-painted pixel-art surfaces, clear pixel clusters and restrained weathering. Create nine distinct seamless square albedo swatches, strictly 3 equal columns by 3 equal rows, touching edge to edge, no gaps, no labels, no borders, no perspective. Square image. Each cell must read as a tileable flat material, with no baked directional shadows. Row 1 left: warm honey oak timber fine directional grain with rare understated knots, middle: darker weathered walnut directional grain, right: warm ivory plaster fine understated aged pixel clusters. Row 2 left: desaturated indigo woven cloth with subtle quilt seams, middle: sage green coarse woven upholstery with tiny tonal stitches, right: warm ivory linen fabric weave. Row 3 left: blue grey stone slabs with irregular subtle mortar joints and chipped pixels, middle: charcoal brushed iron with faint edge scratches but no major highlights, right: muted brick red woven textile with blue and cream sparse geometrical stripe motif. High craftsmanship, consistent palette and controlled pixel density, each tile like 128x128 logical pixels scaled crisply. Not photorealistic, not 3D rendering, not gradients, not noisy. Nine even swatches occupy the entire image exactly. These will be cropped and repeated as game textures.

提示词中的无缝要求属于生成目标；实际产物未做数学无缝保证。不同部件的材质重复频率在 module_3d.gd 和 room_3d.gd 中设置。纹理与真实几何、光照一起构成游戏里的效果。
