# 箱子、背包与存档

## 取物流程

人物走到箱子附近且接近路径未被实体阻挡时，显示“打开箱子 / 漂流便签”。打开后左侧选择物品，右侧显示图标、数量、说明、梗文案；点击加减按钮或输入数字，选择“取入背包”或“一次收好”。箱内库存同步扣除，背包增加，不会凭空重复取物。

按 I 打开背包。补给使用后消耗一份；故事、便签和收藏可以阅读 / 查看，保留物品。关闭面板时箱盖平滑合上。背包跨三个房间保留。

## 修改物品

`assets/meme_items.json` 保存 12 种原创物品的 ID、名称、类型、图标、说明、使用反馈与引用文案。图标在 `assets/item_icons/`。

`loot_controller.gd` 顶部 INITIAL_STOCK 指定每个箱子的初始库存，ROOM_CHESTS 指定箱子位置、标题和便签。增加新物品时同时添加 JSON 定义、PNG 图标和库存引用；库存字典的键必须与物品 ID 一致。

“大肥鱼 / DeepSeek 深潜站 / 鲸落港”是用于游戏的虚构网络梗设定，文案见根目录 `世界观与物品.md`。

## 存档

- 背包与箱子库存：`user://whale_inventory_v5.json`，每次取物 / 使用后自动保存，启动时载入。
- 家具布局：`user://modular_room_25d.json`，游戏窗口中 F5 保存、F9 恢复。
- 自动测试及演示使用独立测试 / 演示文件，不覆盖正常试玩进度。

user:// 是 Godot 用户数据目录，不在工程素材目录中。项目名称变化会改变默认用户目录；要继承旧版背包进度，复制旧版同名存档到新版用户目录。工程压缩包不包含个人进度。

库存转移和背包增加作为同一次保存操作提交；写入失败会回滚库存和背包，避免数量不一致。空箱、非法数量、未知物品、距离不足、重新进入房间及重启恢复均有引擎检查记录。
