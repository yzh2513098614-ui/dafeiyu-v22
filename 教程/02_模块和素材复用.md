# 模块和素材复用

## 将模块放进你的房间

默认游戏使用 `scenes/modules_3d/` 的 124 个独立 `.tscn`。把所需场景拖入 Node3D 场景即可实例化。墙体、窗框、柜子、桌椅、床和灯具主要使用原生三维几何；部分装饰小物使用精灵。每个模块可多次实例化，共享材质与纹理，不必复制素材文件。

完整迁移到另一工程时，复制 `scenes/`、`assets/` 和依赖脚本 `module_3d.gd`、`module.gd`、`modern_materials.gd`、`meme_chest.gd`，保持 res:// 路径；检查具体场景的 ext_resource 依赖。迁移整套玩法还需要房间、氛围、箱子与 UI 脚本。

## 地面、墙面和装饰

- 默认地面由 `room_3d.gd` 调用 `modern_materials.gd` 生成，地砖拼缝在材质里计算。12 个地面共享材质位于 `assets/modern/materials/floor_*.tres`。
- 墙体、收边、横条、踢脚线分别是模块；组合实例便于复用。墙饰、灯带、窗户可单独替换。
- `layouts/*.json` 保存模块 ID、三维位置和角度；复制一份 JSON 修改后可创建更多预设。
- 游戏内素材库按分类筛选；选择地面直接切换地面，选择其他模块进入摆放。
- 三维缩略图在 `assets/modern/thumbnails/`，用于选材预览；复用实际模型请实例化 `.tscn`。

代码保留部分 oak / walnut 等旧 ID，以兼容布局；默认房间使用现代材质。原二维素材、旧材质和原始图集也在包中，供继续修改。

## 导出与生成

在工程目录的终端运行：

```bash
godot --headless --path . --script res://tools/export_modern_materials.gd
godot --path . --script res://tools/render_modern_catalog.gd
```

第一条导出 28 个可复用现代材质；第二条需要图形环境，实际渲染全部模块缩略图。执行后在编辑器中等待资源重新导入。

索引：`现代素材索引.csv`、`三维素材索引.csv`、`素材索引.csv`、`材质索引.csv`、`物品素材索引.csv`。保留全部素材，不依赖教程里省略的路径或外部素材下载。
