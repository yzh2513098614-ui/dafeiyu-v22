# 运行验证和录像

全部检查调用实际 Godot 场景与游戏逻辑，日志位于 `tests/`。UI 检查包含实际鼠标事件点击数量、取物、背包、分类、模块卡片；人物层级检查读取实际渲染帧。

在有图形环境的终端，以 `godot` 表示 Godot 4.6.2 执行文件，运行：

```bash
godot --path . -- --test-ui
godot --path . -- --test-room
godot --path . -- --test-loot
godot --path . -- --test-load
godot --path . -- --test-atmosphere
```

`--test-load` 应紧跟 `--test-loot`，验证上一进程保存后新进程自动恢复；它完成后删除测试进度。检查日志中的 PASS 和 ALL … CHECKS PASSED；进程返回码 0 表示通过。

## 实机录像

`预览/大肥鱼可爱UI_Godot实机演示.mp4` 是 Godot Movie Maker 实际场景录像，42 秒、1000×750、30 FPS。演示包括角色移动、设置和脚边范围、箱子取物、背包、便签、素材分类、家具对话、三个房间及冷暖光。

重录 AVI：

```bash
godot --path . --write-movie 演示.avi --fixed-fps 30 --quit-after 1260 -- --ui-demo
```

转换 MP4：

```bash
ffmpeg -i 演示.avi -c:v libx264 -preset fast -crf 19 -pix_fmt yuv420p -an -movflags +faststart 演示.mp4
```

`--ui-demo` 在固定步长中驱动同一套游戏逻辑和 UI；正常运行是由玩家控制。录像编码帧率不是所有设备实时帧率的承诺。无需 ffmpeg 即可运行游戏，包中 MP4 可直接播放。
