# 导入与试玩

1. 解压整个工程到本地目录，保持 `project.godot` 与 `assets/` 等目录的相对位置。
2. 打开 Godot 4.6.2 项目管理器，点击“导入”，选择本工程的 `project.godot`。
3. 等待图片、字体、SVG 等资源完成首次导入。导入缓存由 Godot 自动生成。
4. 按 F5。默认是小卧室，WASD 移动；顶部按钮切换工作站、咖啡角。
5. 走到灰蓝补给箱旁，出现选项后按 E 或点击“打开箱子”。选择物品，修改数量，点击“取入背包”。按 I 打开背包验证。
6. 点击“素材宝箱”，按类别选择部件，移动鼠标选择位置，左键放置，R 旋转，B 结束。F5 保存布局，F9 恢复。

在游戏窗口中的 F5 保存布局，不会重新启动游戏。退出再启动会自动恢复背包与箱子库存；家具布局需要 F9 手动恢复。

`启动房间.bat` 会尝试使用工程目录中的 `godot.exe` 或 PATH 中的 `godot` 命令。不使用批处理也可以直接从编辑器运行。

## 窗口与渲染

逻辑界面 1448×1086，默认窗口 1000×750，采用 canvas_items 缩放；编辑器渲染设置采用 GL Compatibility。正交摄像机拍摄原生三维模型，人物是 AnimatedSprite3D 四向精灵。

## 导出游戏

在 Godot 编辑器“项目 → 导出”里添加 Windows / Linux 等目标，安装与编辑器版本对应的导出模板，再导出。本包未包含平台执行文件。
