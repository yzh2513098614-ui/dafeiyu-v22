# 人物碰撞和显示层级

## 脚边碰撞

人物实体是 CharacterBody3D，脚边使用 CylinderShape3D：半径 0.19 米、高 0.32 米、中心高度 0.17 米。碰撞体与画面精灵分离；头发、裙摆、尾巴不扩大身体碰撞。家具、箱子和墙体继续使用实际三维碰撞，角色不会因显示在上层就穿过实体家具。

在 `room_3d.gd` 修改 FOOT_RADIUS、FOOT_HEIGHT 常量及 `_player()` 创建形状的位置。半径控制通道宽度，高度控制是否碰到悬空物体；改变形状后也检查 `_place()` 的人物重叠拒绝范围，避免将家具放到脚边。

点击“设置 → 脚边范围”可看到调试圆盘。它仅展示形状底部范围，不改变碰撞。关闭可恢复正常画面。

## 人物始终显示在上方

默认角色 AnimatedSprite3D 使用：

```gdscript
avatar.alpha_cut = SpriteBase3D.ALPHA_CUT_DISABLED
avatar.no_depth_test = true
avatar.render_priority = 127
```

组合透明模式与最高透明绘制优先级，使人物在场景模型之上可见。角色仍使用房间光照；原脚下阴影保留。UI 位于独立 CanvasLayer 20，继续在人物之上。

F8 或设置中的人物选项切换普通遮挡；普通模式恢复深度测试、优先级 0、alpha discard。切换只影响渲染，不移动人物、改变家具或关闭碰撞。

`tests/人物_普通遮挡.png` 和 `tests/人物_优先显示.png` 是真实 Godot 渲染对照：同一人物位置、同一家具、不同显示模式。自动检查对比人物区域像素，验证被柜子遮挡的人物轮廓确实恢复。

## 动画

`assets/animations/` 保留四个方向的待机、行走和互动资源，合计 56 帧。`_build_frames()` 创建 SpriteFrames；行走 8 FPS，移动速度 1.75 米/秒。停止移动保留朝向，互动面向目标；四向动作在游戏中播放。

Godot 官方属性参考：https://docs.godotengine.org/en/stable/classes/class_spritebase3d.html
