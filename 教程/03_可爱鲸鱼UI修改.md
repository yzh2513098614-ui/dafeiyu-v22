# 可爱鲸鱼 UI 修改

## 统一样式

主题来源是 `ui/whale_skin.gd`；`assets/ui/whale_theme.tres` 是已导出的原生 Godot Theme，可拖到 Control 的 Theme 属性里复用。字体、按钮状态、纸张框、卡片、滚动条和输入框由同一个主题定义。

| 资源 | 用途 |
|---|---|
| `whale_mascot.png` | 透明蓝鲸吉祥物 |
| `panel.svg`、`paper.svg`、`sky.svg` | 奶油外框、白纸、蓝色内框 |
| `button.svg`、`hover.svg`、`pressed.svg`、`disabled.svg` | 按钮四种状态 |
| `card.svg`、`selected.svg`、`row.svg` | 素材和物品卡片 |
| `status.svg`、`quote.svg` | 反馈和文案框 |
| `star.svg`、`heart.svg`、`bag.svg`、`chest.svg` | 可复用像素图标 |
| `book.svg`、`wave.svg`、`arrow_up.svg`、`arrow_down.svg` | 辅助图标 |

共 20 个 SVG、1 张透明鲸鱼 PNG、1 个 Theme 资源。框体是 StyleBoxTexture 九宫格，纹理边距 12，像素纹理采用 nearest。拉宽面板时边角保持完整，文字是原生 Label / Button，中文没有烘焙到图片中。

颜色常量 INK、MUTED、BLUE、GOLD 位于 `whale_skin.gd`。修改它们和 SVG 后，运行主题导出脚本更新独立 `.tres`：

```bash
godot --headless --path . --script res://tools/export_whale_theme.gd
```

`tools/build_whale_ui_assets.py` 保存 SVG 生成源文件；运行它会重新生成 SVG，使用修改后的颜色覆盖原文件。

## 修改界面布局

`room_3d.gd` 的 `_ui()` 管理 HUD、对话及设置；`_catalog()` 管理分类和卡片；`loot_controller.gd` 的 `_render()` 管理箱子、背包及便签。坐标使用 1448×1086 逻辑界面尺寸，窗口由 Godot 缩放。

新增按钮可调用 `_button()`，新增文字调用 WhaleSkin.label()，新增框调用 WhaleSkin.panel()。物品说明自动换行，长反馈位于可滚动区域。点击分类或翻页时，旧节点先脱离父节点再 queue_free，避免释放正在发信号的按钮。

UI 位于 CanvasLayer 20；打开模态面板会遮暗房间并暂停角色移动。按钮支持键盘焦点，按 Esc 关闭；拿到物品时背包按钮会短暂缩放反馈。

## 吉祥物制作记录

鲸鱼 PNG 使用图像生成工具，根据用户提供的大肥鱼标题图的蓝白、奶油、金色星星风格制作；参考图未直接切片作为 UI。生成要求：透明背景、胖蓝鲸、奶油条纹腹部、开心闭眼、粉色脸颊、小水柱、便签本、少量金色星星及波浪、像素插画、不带文字，独立可复用。

SVG 是可编辑的代码生成几何素材，字体是许可随包附带的 Noto Sans SC。UI 字符始终来自游戏代码，便于本地化。
