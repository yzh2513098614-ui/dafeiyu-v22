# 加固容器版更新记录

在潮汐版 52 个模型文件基础上，新增 12 种原创容器，每种提供闭合和开启两份 GLB，共 24 个；再新增现代补给室布局，合计 77 个模型文件。保留餐厅、海滩、潮汐和原有保险盒。

参考三角洲行动中航空箱、加固箱和保险柜的结构语言，使用金属包边、厚护角、凹陷面板、双卡扣、锁盘、握把与内腔分隔。没有复制游戏网格或贴图。

新增慢速开闭控制器：默认 2.4 秒，翻盖与柜门打开 105 度，抽屉平移。重型保险柜先收回锁栓，再旋转柜门。新增交互预览设为默认入口，仍可进入总览与潮汐场景。

官方 Godot 4.4.1 无界面导入和三个演示场景启动检查完成；1,823 项实际导入后部件姿态检查通过。GPU 视觉渲染尚未实测。具体使用方法和局限见 README 与容器设计说明。
