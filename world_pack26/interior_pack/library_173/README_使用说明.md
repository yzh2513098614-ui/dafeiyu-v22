# 大肥鱼同人SLG：Godot 三维物品与海滨建筑素材包

依据参考视频中的固定斜俯视角、蓝灰与奶白配色、清楚的顶面侧面关系，制作的一套原创低多边形三维网格。模型采用简洁的实体结构和分色材质，适合你的 2.5D 场景与二维角色搭配。

**交付的是实际 .glb 网格，不是用一张图片冒充三维模型。** 每个模型含顶点、三角面、法线和 PBR 材质。预览 PNG 直接渲染自同一份模型几何；预览使用简化软件光照，Godot 中的最终阴影与色调取决于场景灯光。

## 在 Godot 使用

1. 解压后，用 Godot 4.x 导入本目录的 `project.godot`，等待 GLB 导入完成。
2. 运行主场景，进入新增 48 件装饰物的分类预览；右侧按分类、场景、摆放方式或关键词筛选。点击“查看全部三维素材”进入 173 个模型的总览，再进入容器或潮汐预览。容器预览按 E 开关；右键拖动旋转、滚轮缩放，按 R 恢复斜俯视角。
3. 在自己的三维项目里，将 `models` 文件夹复制到项目根目录。
4. 想要视觉模型，拖入 `.glb`；想要附带简化碰撞体，拖入同名 `.tscn`。
5. 同名 `.tscn` 使用 `res://models/...` 路径。若移动到其他路径，需更新资源引用。

坐标采用 **Y 轴向上，单位为米，正面朝 -Z**。普通物品根节点位于底部中心附近；栈桥包含水面以下的支柱，根节点位于安装基准附近。模型顶点与材质可在 Blender 等支持 glTF 的软件中继续编辑。导入到 Godot 后可通过“新建继承场景”调整组件或材质。

默认建议采用正交摄像机，从水平面抬高约 28–35 度观察，水平斜转约 35–40 度，搭配柔和的方向光。角色若使用二维立绘，可使用 Sprite3D，并根据你的遮挡规则设置朝向与透明材质。

## 建筑与碰撞

- **restaurant_cutaway**：前墙和右墙降低，保留中央入口；室内餐桌、椅子与吧台为独立命名部件，适合斜俯视观察。碰撞包含地板、墙体与家具。
- **restaurant_exterior**：完整屋顶与外立面，适合城市场景摆放。门窗是视觉部件，碰撞覆盖整个主体；若要进入内部，可切换到室内剖面场景或自行添加场景入口逻辑。
- **beach_kiosk**：饮品服务窗口、屋顶、柜台、杯子与招牌。
- **lifeguard_tower**：高架观察舱、阶梯、支柱与旗帜。该建筑当前为视觉模型，未提供角色登塔所需的精细楼梯碰撞。
- **lighthouse**：蓝白分段塔身、灯室、屋顶与底座，采用主体近似碰撞。
- **wooden_pier**：逐片木板、底梁、支柱和栏杆，包含桥面与栏杆的简化碰撞。
- **组合场景**：保留独立部件，包含从子物品传递的简化碰撞；海面没有水体模拟或游泳逻辑。

海滨缓坡的精确地面碰撞由 `tidal_coast.gd` 在加载时根据网格创建。只拖入静态海滨 GLB/同名包装时，没有该缓坡的自动地面碰撞；需要可行走的潮汐地面时请使用 `tidal_coast.tscn`，或自行创建地形碰撞。

桌椅等物品使用包围盒碰撞；椰子树、路灯、沙滩伞使用较窄的近似碰撞，避免树冠和伞面挡住角色。所有碰撞仍应结合你实际角色胶囊大小微调。没有烘焙导航网格。

## 动态潮汐如何使用

把 `models/`、`shaders/`、`tidal_coast.gd` 和 `tidal_coast.tscn` 复制到自己项目，保持这些相对路径。将 `tidal_coast.tscn` 放入你的三维场景即可；该场景不会添加摄像机或界面。可以移动、旋转它，岸线计算使用场景自己的局部坐标。放缩该节点会同时放缩地形和视觉潮差；水深查询仍以本地单位返回数值。

默认水位从 **-0.18 m 到 +0.18 m**，海滩缓坡斜率为 **0.16**，岸线高低潮之间前后移动 **2.25 m**。这些是游戏示范参数，可调整，不表示真实港口的潮汐数据。默认 **180 秒完成低潮→高潮→低潮一周期**，波纹和浮标以约数秒的节奏轻微变化。

涨潮时，水面随水位上升，岸线向陆地推进；退潮露出礁石下缘、海藻、贝壳、漂流木和湿沙。湿沙会逐步变干，泡沫沿弯曲岸线缓慢改变透明度，浮标跟随水位轻微起伏。水位标尺、栈桥支柱常年水线与潮汐本身分开，便于观察。

| 参数／接口 | 作用 |
|---|---|
| `cycle_seconds` | 自动潮汐周期，默认 180 秒；演示 UI 文案按默认值显示 |
| `low_level` / `high_level` | 最低、最高水位；当前地形建议保持在默认范围附近，并满足 low_level < high_level |
| `wave_amplitude` | 波纹幅度，默认 0.014 m |
| `automatic` | 是否自动循环 |
| `frozen` | 暂停潮汐、波纹、泡沫和浮标动画 |
| `set_manual_level(level)` | 平滑切换到指定水位，默认在数秒内完成高低潮切换 |
| `resume_cycle()` | 从当前水位恢复自动循环 |
| `tide_changed(level, shore_z)` | 水位变化信号；shore_z 是 x=0 位置的岸线局部 Z 坐标 |
| `get_depth_at(local_point)` | 查询地形表面相对于水面的深度；正数表示水下，负数表示干地 |

角色要查询是否踏入水中，先将世界位置转换到潮汐场景的局部坐标，再调用 `get_depth_at()`。该函数只描述海岸地面与水位关系，使用时要限制在本模型范围内；栈桥上的角色仍站在桥面上，不能仅凭桥下水深就判定角色落水。

这套潮汐属于可调的视觉与地形交互模块，没有流体动力学、浮力物理或现成游泳控制器。单独 GLB 只保存几何与静态材质，动态效果由配套 Godot 脚本和着色器提供。`beach_low_tide.glb` 与 `beach_high_tide.glb` 则是两份独立的真实网格快照。

材质接口与地面碰撞方式参照 Godot 官方文档：

- https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html
- https://docs.godotengine.org/en/stable/classes/class_meshinstance3d.html
